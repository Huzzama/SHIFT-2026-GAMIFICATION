# 8. Recompensas y Progreso

FARO da puntos por **persistir**, no por hacer clic. Todo lo que otorga puntos exige que algo real haya ocurrido: una actividad terminada, un módulo cerrado, una vuelta después de desconectarse, una respuesta que a alguien le sirvió.

### Cómo se ganan los puntos

| Acción | Puntos | Regla exacta |
| --- | --- | --- |
| Completar una actividad | **10** | Una sesión de estudio registrada sobre un hito. |
| Cerrar un módulo | **50** | Se paga una sola vez, cuando el último hito del módulo queda completado. |
| Bono de ritmo | **+5** | Cada 3 días consecutivos con actividad. No se pierde lo ganado si se rompe la racha: solo deja de sumar. |
| Bono de regreso | **+25** | Se paga una vez cuando vuelves tras 3 o más días sin actividad (el umbral de fricción) y completas algo. |
| Respuesta marcada como útil | **+5** | Otro estudiante marcó tu respuesta como útil en Comunidad. |
| Terminar una sala de estudio | **+20** | Entrar a la sala no da puntos. Terminar la sesión completa, sí. |

**Canje:** 100 puntos = 1 unidad de recompensa. La pantalla de Recompensas muestra el desglose por origen — curso, ritmo, regreso, comunidad — para que siempre se pueda auditar de dónde salió cada punto.

### Logros de resiliencia

Son cinco. Ninguno se gana por entrar a la app.

| Logro | Se gana cuando |
| --- | --- |
| **The Comeback** | Vuelves tras 3 o más días sin actividad y completas una actividad. |
| **Back on Track** | Llevas al menos 2 sesiones registradas y tu impulso vuelve a 65 % o más. |
| **Weathered the Storm** | Completas una sesión teniendo 2 o más actividades vencidas al empezarla. |
| **Smart Session** | Completas una sesión que cabía en el tiempo que declaraste tener. |
| **Finisher** | Tu progreso llega a 100 %. |

Mientras un logro no está ganado, FARO muestra una **pista** de qué haría falta. Nunca un reproche.

### Reconocimientos de comunidad

| Reconocimiento | Se gana cuando |
| --- | --- |
| **Community Builder** | Participas de forma sostenida en el espacio del curso. |
| **Knowledge Sharer** | Compartes recursos o apuntes que otros usan. |
| **Helpful Peer** | Tus respuestas acumulan marcas de útil. |
| **Study Companion** | Completas salas de estudio acompañando a otros. |
| **Community Comeback** | Vuelves a la comunidad después de un periodo ausente. |

### Progreso

El porcentaje de progreso **no lo inventa FARO**: sale de Canvas. Es actividades con entrega registrada ÷ actividades totales del curso. Una fecha vencida no cuenta como «hecha», y una actividad que no pertenece a ningún módulo no entra en el conteo.

El **impulso (momentum)** es distinto del progreso: mide conexión actual con el aprendizaje, en una ventana de 14 días, con piso en 20. Nunca baja a cero. El progreso ganado no se pierde jamás.
